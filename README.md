# 8-bit ALU using Verilog

An 8-bit Arithmetic Logic Unit (ALU) designed in Verilog HDL and verified using a testbench.

## About
The ALU takes two 8-bit inputs and a select signal, and performs arithmetic and logical operations on them.

## Tools used
- Verilog HDL
- Cadence / Vivado (simulation)

## Files
- `ALU_8bit.v` : ALU design code
- `ALU_8bit_tb.v` : testbench
